# WHATS POPPIN

כל הפופ-אפים בישראל במקום אחד: אוכל, אופנה ועיצוב, שווקים, אמנות ותרבות, ילדים ומשפחה, השקות מותגים ועוד.
**אתר** שמותאם לטלפון ונראה כמו אפליקציה (Next.js), עם Supabase כמסד נתונים.
האתר זמין ב**עברית**, ב**ערבית** (`/ar`) וב**אנגלית** (`/en`). מחליפים שפה בלחיצה אחת למעלה, והאתר זוכר את הבחירה.

**עיקרון מס' 1: ידידותיות למשתמש מעל הכל.** אם משהו מבלבל, מפשטים אותו או מוותרים עליו.

> **מצב הדגמה:** עד שמחברים את Supabase, האתר עובד עם 25 פופ-אפים לדוגמה מובנים, כך שאפשר להעלות אותו לאוויר ולהסתכל עליו כבר עכשיו. התחברות, הגשת פופ-אפים, ניהול ותזכורות מתחילים לעבוד אחרי החיבור.

## להעלות את האתר לאוויר (רק לחיצות, בלי טרמינל)

### חלק 1: מסד הנתונים ב-Supabase (כ-10 דקות)

1. נכנסים ל-https://supabase.com, נרשמים (אפשר עם GitHub) ולוחצים **New project**.
2. **Name:** `whats-poppin`. **Region:** Central EU (Frankfurt), הכי קרוב לישראל. בוחרים סיסמה ושומרים אותה. לוחצים **Create**.
3. פותחים את [`supabase/setup.sql`](supabase/setup.sql) ב-GitHub ולוחצים על **Copy raw file** (אייקון של שני ריבועים, מעל הקוד).
4. ב-Supabase, בתפריט השמאלי: **SQL Editor**. מדביקים ולוחצים **Run**. צריך להופיע **Success**.
5. **Authentication → Sign In / Providers**:
   - מפעילים **Allow anonymous sign-ins**. בזכות זה אפשר לשמור פופ-אפים ולקבל תזכורות בלי להירשם.
   - מוודאים ש-**Email** מופעל.
6. **Project Settings → API Keys**. מעתיקים בצד שלושה דברים:
   - **Project URL**
   - המפתח הציבורי **anon / publishable**
   - המפתח הסודי **service_role / secret**. שומרים אותו בסוד ולא משתפים.

### חלק 2: האתר ב-Vercel (כ-5 דקות)

1. נכנסים ל-https://vercel.com ונרשמים עם **Continue with GitHub**.
2. **Add New → Project**, ובוחרים את הריפו `popups-app` → **Import**.
3. **Root Directory:** לוחצים **Edit** ובוחרים `apps/web`.
4. פותחים **Environment Variables** ומוסיפים את המשתנים מהטבלה למטה.
5. לוחצים **Deploy**. אחרי כדקה מקבלים קישור לאתר. 🎉

### חלק 3: חיבור אחרון (כ-3 דקות)

1. **כתובת האתר:** ב-Supabase: **Authentication → URL Configuration**.
   - **Site URL:** כתובת האתר מ-Vercel (למשל `https://whats-poppin.vercel.app`).
   - **Redirect URLs:** מוסיפים `https://<הכתובת שלכם>/auth/callback`.
2. **מייל התחברות** (אחרי שמחברים שירות מיילים ב-**Authentication → Emails → SMTP Settings**, למשל Gmail ייעודי לאתר):
   ב-**Authentication → Emails → Magic link or OTP**, ב-Subject כותבים `הכניסה שלך ל-WHATS POPPIN`, וב-Body (לשונית Source) מדביקים:
   ```html
   <div dir="rtl" style="font-family:Arial,sans-serif;font-size:16px;line-height:1.6">
     <h2>הכניסה שלך ל-WHATS POPPIN</h2>
     <p>הקוד שלך:</p>
     <p dir="ltr" style="font-size:28px;font-weight:bold;letter-spacing:4px">{{ .Token }}</p>
     <p>או פשוט לוחצים כאן: <a href="{{ .SiteURL }}/auth/callback?token_hash={{ .TokenHash }}&type=email">כניסה לאתר</a></p>
     <p style="color:#555">הקוד והקישור תקפים לזמן קצר ולשימוש אחד. אם לא ביקשת להיכנס, אפשר להתעלם מהמייל.</p>
   </div>
   ```
   הקישור הזה עובד בכל דפדפן ובכל מכשיר, גם אם פותחים את המייל בטלפון.
3. **להפוך את עצמכם למנהלים:**
   - נכנסים לאתר ומתחברים פעם אחת עם המייל שלכם (פרופיל → התחברות).
   - ב-Supabase → **SQL Editor** מריצים את השורה הבאה, עם המייל שלכם:
     ```sql
     update profiles set role = 'admin' where id = (select id from auth.users where email = 'YOUR@EMAIL.COM');
     ```
   - רעננו את האתר. בפרופיל יופיע **"לפאנל הניהול"**.
4. **כתובת האתר ב-Vercel:** אם עוד לא עשיתם את זה, מוסיפים את `NEXT_PUBLIC_SITE_URL` עם כתובת האתר ועושים **Redeploy**.

### איך בודקים שהכל עובד
- **חיבור למסד הנתונים:** בפרופיל, תחת "בדיקת מערכת", צריך להופיע **"מחובר · 25 פופ-אפים פעילים"**.
- **התחברות:** מתחברים עם המייל ובודקים שמגיע מייל עם קוד.
- **הגשה ואישור:** ב"לעסקים" מגישים פופ-אפ לניסיון, ואז מאשרים אותו ב"ניהול → לאישור".

## משתני סביבה (Vercel → Project → Settings → Environment Variables)

| משתנה | חובה? | מה זה ומאיפה |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | כן | Project URL מ-Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | כן | המפתח הציבורי anon / publishable |
| `NEXT_PUBLIC_SITE_URL` | מומלץ | כתובת האתר, למשל `https://whats-poppin.vercel.app` (ל-sitemap ולגוגל) |
| `SUPABASE_SERVICE_ROLE_KEY` | לתזכורות | המפתח הסודי service_role. **רק ב-Vercel**, אף פעם לא בקוד |
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | לתזכורות | מפתח Push ציבורי (ראו למטה) |
| `VAPID_PRIVATE_KEY` | לתזכורות | מפתח Push פרטי. סודי |
| `CRON_SECRET` | לתזכורות | מחרוזת אקראית ארוכה. Vercel משתמש בה כדי להפעיל את שליחת התזכורות פעם ביום |
| `NEXT_PUBLIC_CONTACT_EMAIL` | מומלץ | מייל ליצירת קשר. משמש בעמוד "צרו קשר", בהצהרת הנגישות, בתנאי השימוש ובמדיניות הפרטיות |
| `VAPID_SUBJECT` | לא | `mailto:` של כתובת ליצירת קשר (ברירת מחדל: hello@whatspoppin.app) |
| `GOOGLE_MAPS_API_KEY` | לא | איתור כתובות מדויק יותר בעברית. בלעדיו האתר משתמש ב-OpenStreetMap, בחינם |

**מפתחות Push:** אפשר לייצר זוג חדש עם `npx web-push generate-vapid-keys`.

**מה פרטי ומה ציבורי:** כל מה שמתחיל ב-`NEXT_PUBLIC_` גלוי בדפדפן, ולכן שמים בו רק ערכים ציבוריים.

## איך דברים עובדים (בקצרה)

- **"פתוח עכשיו":** מחושב לפי השעון של הגולש ואזור הזמן של הפופ-אפ. פופ-אפים שהסתיימו נעלמים מהרשימות אוטומטית.
- **"לוהט עכשיו":** הציון מחושב מצפיות, שמירות, ניווטים ושיתופים ב-24 השעות האחרונות, ומקבל תוספת לפופ-אפים שנגמרים בקרוב או שנפתחו לאחרונה.
  - הציון מתעדכן לבד כל 10 דקות.
  - המשקלות נמצאים בטבלה `app_config` (`hot_score_weights`), ואפשר לשנות אותם בלי קוד.
- **ממומן:**
  - **איפה מופיע:** בתחילת "לוהט עכשיו" ו"קרוב אליך", ועם סימון מיוחד במפה.
  - **כמה:** לכל היותר פריט ממומן אחד מכל 5 (`sponsored_every_n` ב-`app_config`).
  - **סימון:** תמיד מסומן "ממומן".
  - **תשלום:** אפשר לחבר בהמשך דרך העמודות `payment_status` / `payment_reference` בטבלה `promotions`.
- **תזכורות:** פעם ביום (10:00 שעון ישראל) נשלחת התראה למי ששמר פופ-אפ שנגמר תוך 36 שעות. מי שאין לו התראות יכול להשתמש בכפתור "תזכורת ביומן" בעמוד הפופ-אפ.
- **הרחבה למדינות נוספות:** מדינות וערים הן נתונים בטבלאות `countries` / `cities`. כל פופ-אפ שומר את אזור הזמן שלו.

## למפתחים

```bash
npm install
cp apps/web/.env.example apps/web/.env.local   # אפשר גם להשאיר ריק: מצב הדגמה
npm run dev                                    # http://localhost:3000
npm test                # לוגיקת הסטטוסים + מנוע ההדגמה
npm run typecheck
npm run build
npm run db:test         # setup.sql + בדיקות SQL על Postgres+PostGIS מקומי
npm run db:setup-file   # אחרי שינוי במיגרציות או ב-seed: בונה מחדש את setup.sql ואת נתוני ההדגמה
```

**מבנה הריפו:**
```
apps/web/                 האתר (Next.js 16): עמודים ב-src/app, תכונות ב-src/features, רכיבים ב-src/components
packages/shared/          לוגיקת סטטוס, טיפוסים, קטגוריות, תרגומים (src/i18n/he.json), מנוע הדגמה
supabase/migrations/      הסכמה, RLS ופונקציות (popup_list, discover_feed, popup_details, hot score...)
supabase/setup.sql        כל המיגרציות + seed בקובץ אחד, להדבקה ב-SQL Editor
supabase/tests/           בדיקות SQL
apps/mobile/              גרסת אפליקציה (Expo). בהמתנה
```

**מערכת העיצוב:**
- **מקורות:** טוקנים ב-`apps/web/src/app/globals.css`, ותצוגה חיה בכתובת `/design`.
- **צבעים:** ראשי `#C2410C`. כל צמד טקסט ורקע עומד ב-WCAG AA.
- **טקסט:** גופן Rubik, ושום טקסט לא קטן מ-15px.
- **נגישות:** כל כפתור הוא לפחות 48×48.
- **שפה:** עברית וערבית מימין לשמאל, אנגלית משמאל לימין. כל הטקסטים בקבצים `packages/shared/src/i18n/{he,ar,en}.json`.
