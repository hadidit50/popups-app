# WHATS POPPIN

כל הפופ-אפים בישראל במקום אחד: אוכל, אופנה ועיצוב, שווקים, אמנות ותרבות, ילדים ומשפחה, השקות מותגים ועוד.
אפליקציה ל-iOS ול-Android (Expo + React Native), עם Supabase כשרת.

**עיקרון מס' 1: ידידותיות למשתמש מעל הכל.** אם משהו מבלבל, מפשטים אותו או מוותרים עליו.

## שלב א': יצירת פרויקט Supabase (פעם אחת, כ-10 דקות)

1. נכנסים ל-https://supabase.com/dashboard ולוחצים **New project**.
2. שם: `whats-poppin`. אזור (Region): **Central EU (Frankfurt)**, הכי קרוב לישראל. בוחרים סיסמה חזקה למסד הנתונים ושומרים אותה.
3. מחכים כדקה עד שהפרויקט מוכן.
4. מעלים את הסכמה ואת נתוני הדוגמה. בטרמינל, מתיקיית הפרויקט:
   ```bash
   npx supabase login
   npx supabase link --project-ref <PROJECT_REF>     # ה-ref מופיע בכתובת של הדשבורד: /project/<PROJECT_REF>
   npx supabase db push --include-seed
   ```
   > דרך חלופית בלי טרמינל: בדשבורד → **SQL Editor**, מדביקים ומריצים לפי הסדר את שלושת הקבצים שב-`supabase/migrations/`, ואחריהם את `supabase/seed.sql`.
5. מפעילים שמירה בלי הרשמה: **Authentication → Sign In / Providers → Allow anonymous sign-ins → On**. (נדרש משלב 4.)
6. מעתיקים את המפתחות: **Project Settings → API Keys** (או **API**). צריך את ה-**Project URL** ואת המפתח הציבורי (**anon** / **publishable**).

> ⚠️ את המפתח `service_role` / `secret` **לעולם** לא שמים באפליקציה. הוא ישמש רק את פאנל הניהול בצד השרת (שלב 7).

### נתוני הדוגמה

25 פופ-אפים מאושרים ב-6 ערים (תל אביב, ירושלים, חיפה, ראשון לציון, באר שבע, אילת), בכל 7 הקטגוריות. בנוסף יש:
- פופ-אפ אחד שממתין לאישור (לא מוצג באפליקציה)
- 2 פופ-אפים ממומנים
- קצת פעילות מ-24 השעות האחרונות, כדי שלציון "לוהט עכשיו" תהיה התחלה

**כל התאריכים יחסיים ליום שבו מריצים את ה-seed**, כך שתמיד יש מה שפתוח עכשיו ומה שנגמר בקרוב. כדי לרענן, מריצים שוב את ה-seed על מסד נקי (`npx supabase db reset --linked`; **זה מוחק את כל הנתונים**).

התמונות הן תמונות דוגמה מ-Unsplash. אם תמונה לא נטענת, האפליקציה מציגה במקומה את צבע הקטגוריה עם האייקון שלה.

## שלב ב': הרצת האפליקציה בטלפון

```bash
npm install                                    # פעם אחת, מתיקיית השורש
cp apps/mobile/.env.example apps/mobile/.env.local
# פותחים את apps/mobile/.env.local וממלאים את 2 הערכים משלב א' (סעיף 6)
npm run mobile
```

סורקים את קוד ה-QR: **ב-iPhone** עם המצלמה, **ב-Android** מתוך אפליקציית Expo Go.
אם הטלפון והמחשב לא באותה רשת Wi-Fi: `npm run mobile -- --tunnel`.

## משתני סביבה

| משתנה | איפה | חובה מאיזה שלב | מה זה |
|---|---|---|---|
| `EXPO_PUBLIC_SUPABASE_URL` | `apps/mobile/.env.local` | 1 | כתובת הפרויקט ב-Supabase |
| `EXPO_PUBLIC_SUPABASE_ANON_KEY` | `apps/mobile/.env.local` | 1 | המפתח הציבורי (anon / publishable) |
| `SUPABASE_SERVICE_ROLE_KEY` | פאנל הניהול, צד שרת בלבד | 7 | מפתח מנהל. לא נכנס לאפליקציה לעולם |
| `GOOGLE_MAPS_API_KEY` | סוד של Edge Function (`npx supabase secrets set`) | 7 | המרת כתובות לקואורדינטות בפאנל הניהול |
| `EXPO_PUBLIC_GOOGLE_MAPS_ANDROID_KEY` | `apps/mobile/.env.local` | 3 (רק בבילד של חנות) | מפות Google ב-Android. ב-Expo Go לא נדרש |

כל משתנה שמתחיל ב-`EXPO_PUBLIC_` נארז בתוך האפליקציה, ולכן שמים בו רק ערכים ציבוריים.

## בדיקות

```bash
npm test            # לוגיקת הסטטוס ("פתוח עכשיו", "נפתח ב-18:00", "מסתיים בעוד יומיים"...)
npm run typecheck   # TypeScript בכל החבילות
npm run db:test     # מריץ מיגרציות + seed + בדיקות SQL על Postgres+PostGIS מקומי (בלי Docker)
```

`db:test` דורש Postgres ו-PostGIS מותקנים מקומית. עם Docker אפשר במקום זה להריץ `npx supabase start` ואז `npx supabase db reset`.

## מערכת העיצוב (בקצרה)

- **צבעים:** כתום חם `#C2410C` כצבע ראשי. כל צמד של טקסט ורקע עומד ב-WCAG AA (ניגודיות 4.5:1 לפחות). סטטוס תמיד מופיע **במילים**, והצבע רק מחזק אותו.
- **קטגוריות:** לכל קטגוריה צבע **ואייקון**, כדי שגם עיוורי צבעים יבחינו ביניהן.
- **טקסט:** הגופן Rubik, ושום טקסט לא קטן מ-15. הגדלת הגופן של המערכת פעילה בכל מקום.
- **מגע:** כל כפתור הוא לפחות 48×48, ולכל אחד יש תיאור לקורא מסך (`accessibilityLabel`).
- **RTL:** האפליקציה תמיד מימין לשמאל, וכל הטקסטים נמצאים בקובצי תרגום.
- **תצוגה חיה:** במסך **פרופיל → למפתחים → תצוגת מערכת העיצוב** (מופיע רק במצב פיתוח).

הטוקנים נמצאים ב-`apps/mobile/src/ui/theme.ts` והרכיבים ב-`apps/mobile/src/ui/components/`.

## תקלות נפוצות

- **האפליקציה נפתחת משמאל לימין:** סוגרים את Expo Go לגמרי ופותחים שוב. בהפעלה הראשונה האפליקציה עוברת ל-RTL ונטענת מחדש פעם אחת.
- **"Supabase לא מוגדר" במסך הפרופיל:** קובץ `apps/mobile/.env.local` חסר או ריק. אחרי שממלאים אותו, עוצרים את `npm run mobile` ומריצים שוב.
- **"אין חיבור לשרת":** בודקים שהכתובת והמפתח הועתקו במלואם ושהמיגרציות רצו (שלב א', סעיף 4).
