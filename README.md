# WHATS POPPIN

כל הפופ-אפים בישראל במקום אחד: אוכל, אופנה ועיצוב, שווקים, אמנות ותרבות, ילדים ומשפחה, השקות מותגים ועוד.
**אתר** שמותאם לטלפון ונראה כמו אפליקציה (Next.js), עם Supabase כמסד נתונים.

**עיקרון מס' 1: ידידותיות למשתמש מעל הכל.** אם משהו מבלבל, מפשטים אותו או מוותרים עליו.

---

## מה יש בריפו

```
apps/web/           האתר (Next.js): עמודים ב-src/app, רכיבי עיצוב ב-src/components
packages/shared/    קוד משותף: לוגיקת "פתוח עכשיו", טיפוסים, קטגוריות ותרגומים (src/i18n/he.json)
supabase/           מסד הנתונים: מיגרציות, נתוני דוגמה, setup.sql (הכל בקובץ אחד) ובדיקות
apps/mobile/        גרסת האפליקציה (Expo). בהמתנה, לא בפיתוח כרגע
```

## להעלות את האתר לאוויר (רק לחיצות, בלי טרמינל)

### חלק 1: מסד הנתונים ב-Supabase (כ-10 דקות)

1. נכנסים ל-https://supabase.com, נרשמים (אפשר עם GitHub) ולוחצים **New project**.
2. **Name:** `whats-poppin`. **Region:** Central EU (Frankfurt), הכי קרוב לישראל. בוחרים סיסמה ושומרים אותה. לוחצים **Create**.
3. מחכים כדקה שהפרויקט יהיה מוכן.
4. פותחים את הקובץ [`supabase/setup.sql`](supabase/setup.sql) ב-GitHub. מעל הקוד יש כפתור **Copy raw file** (אייקון של שני ריבועים). לוחצים עליו.
5. ב-Supabase, בתפריט השמאלי: **SQL Editor**. מדביקים (Command+V) ולוחצים **Run**.
   צריך להופיע **Success**. זה יוצר את כל הטבלאות וגם 25 פופ-אפים לדוגמה.
6. **Authentication → Sign In / Providers → Allow anonymous sign-ins → On**. (נדרש משלב 4, כדי שאפשר יהיה לשמור בלי הרשמה.)
7. **Project Settings → API Keys**. מעתיקים לצד שני דברים:
   - **Project URL** (כתובת שנראית כמו `https://xxxx.supabase.co`)
   - המפתח הציבורי: **anon** או **publishable**

> ⚠️ את המפתח `service_role` / `secret` לא מדביקים בשום מקום חוץ מהגדרות השרת בשלב 7.

### חלק 2: האתר ב-Vercel (כ-5 דקות)

1. נכנסים ל-https://vercel.com ונרשמים עם **Continue with GitHub**.
2. **Add New → Project**, ובוחרים את הריפו `popups-app` → **Import**.
3. **Root Directory:** לוחצים **Edit** ובוחרים `apps/web`.
4. פותחים **Environment Variables** ומוסיפים שני משתנים, עם הערכים מחלק 1, סעיף 7:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
5. לוחצים **Deploy**. אחרי כדקה מקבלים קישור לאתר. 🎉

מעכשיו, כל שינוי שנכנס לענף הראשי (`main`) מתעדכן באתר לבד.

## משתני סביבה

| משתנה | איפה | מאיזה שלב | מה זה |
|---|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Vercel (ו-`apps/web/.env.local` להרצה מקומית) | 1 | כתובת הפרויקט ב-Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | כנ"ל | 1 | המפתח הציבורי (anon / publishable) |
| `SUPABASE_SERVICE_ROLE_KEY` | Vercel בלבד | 7 | מפתח מנהל לפאנל הניהול. לא נחשף לדפדפן |
| `GOOGLE_MAPS_API_KEY` | Vercel בלבד | 7 | המרת כתובת לנקודה על המפה בפאנל הניהול |

כל מה שמתחיל ב-`NEXT_PUBLIC_` גלוי בדפדפן, ולכן שמים בו רק ערכים ציבוריים.

## נתוני הדוגמה

25 פופ-אפים מאושרים ב-6 ערים (תל אביב, ירושלים, חיפה, ראשון לציון, באר שבע, אילת), בכל 7 הקטגוריות. בנוסף יש:
- פופ-אפ אחד שממתין לאישור
- 2 פופ-אפים ממומנים
- פעילות מ-24 השעות האחרונות, כדי שלציון "לוהט עכשיו" תהיה התחלה

**התאריכים יחסיים ליום שבו מריצים את setup.sql**, כך שתמיד יש מה שפתוח עכשיו ומה שנגמר בקרוב.
התמונות הן תמונות דוגמה מ-Unsplash. אם תמונה לא נטענת, מוצגים במקומה צבע הקטגוריה והאייקון שלה.

## למפתחים

```bash
npm install
cp apps/web/.env.example apps/web/.env.local   # ממלאים את 2 הערכים
npm run dev                                    # http://localhost:3000
npm test                # לוגיקת הסטטוסים ("פתוח עכשיו", "מסתיים בעוד יומיים"...)
npm run typecheck
npm run build           # בילד של האתר
npm run db:test         # setup.sql + בדיקות SQL על Postgres+PostGIS מקומי
npm run db:setup-file   # בונה מחדש את supabase/setup.sql אחרי שינוי במיגרציות או ב-seed
```

**מערכת העיצוב:**
- **מקורות:** הטוקנים נמצאים ב-`apps/web/src/app/globals.css` והרכיבים ב-`apps/web/src/components/`. יש גם תצוגה חיה בכתובת `/design`.
- **צבעים:** ראשי `#C2410C`. כל צמד טקסט ורקע עומד ב-WCAG AA. סטטוס מוצג תמיד במילים, לא רק בצבע.
- **טקסט:** גופן Rubik, ושום טקסט לא קטן מ-15px. הגדלים ב-rem, כך שזום של הדפדפן עובד.
- **נגישות:** כל כפתור הוא לפחות 48×48. מקלדת: מסגרת פוקוס ברורה וקישור "דילוג לתוכן".
- **שפה:** RTL מלא, וכל הטקסטים נמצאים ב-`packages/shared/src/i18n/he.json`.
